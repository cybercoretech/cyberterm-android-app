First release · 0.1.0

A capable local terminal, with a clear scope.

Cyberterm Android brings the terminal engine to the Android app sandbox. It runs a real shell and terminal programs that are available to that sandbox.

01 // SHELL

A real Android shell

Interactive `/system/bin/sh` in a PTY. Commands run as the app's unprivileged Android user.

02 // ENGINE

Cyberterm's Rust core

Same GPU terminal, font rendering, input handling, and configuration engine as the desktop project.

03 // PRIVACY

Private and offline

No network or storage permission. Files and configuration stay inside the app's private directory.

RUNS ON YOUR DEVICE

A real shell in your pocket.

This screenshot was captured on a Galaxy S25 Ultra. Cyberterm starts in its writable home directory (~) and runs Android's local shell.

Command availability follows Android. File and text tools such as ls, cp, grep, and head work inside app storage. less uses Android's more pager. Stock Android has no sudo; kill is limited to app-owned processes. This app has no Internet permission, so curl and ping cannot reach external hosts.

INSTALL // ANDROID 8+

Pick up the terminal.

Install from the Cybercore F-Droid repository, or download the APK. Android requires a confirmation before installing an APK downloaded from a browser or terminal.

Requires Android 8.0+ · arm64-v8a or x86_64 · one APK includes both native architectures.
